# 🚀 일본 IT 취업 도전기 (Infrastructure Engineer)

### 👨‍💻 안녕하세요, 성장을 멈추지 않는 엔지니어 지망생입니다!
저는 현재 **특성화고등학교 컴퓨터공학과 3학년**에 재학 중인 학생입니다. 

미래에 대한 고민 중 '네트워크'라는 길을 발견했고, **시스템 및 네트워크 엔지니어**라는 직업에 깊은 흥미를 느껴 관련 대회 참가와 자격증 취득에 도전해왔습니다.

이 곳은 꿈을 향한 저의 **'一歩(한 걸음)'**을 기록하는 공간입니다. 매일의 실습과 학습 내용을 꼼꼼히 기록하며 실력을 증명해 나가겠습니다.
